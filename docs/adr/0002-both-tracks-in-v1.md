# Class A and Class B ship together in v1

Considered building Class B (Tactical JIT) alone first as a vertical slice to prove out the AI Teacher/Sandbox/Evaluation core before adding curriculum sequencing. Rejected: v1 must include both Class A (Structured Curriculum) and Class B (Tactical Sprint) from the start, per product intent. This means the Concept Graph, curriculum authoring, and the Class Synchronization/Spaced Refresher mechanics (Section 3.1.3) are in scope for v1, not deferred.
