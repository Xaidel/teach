# Deterministic checks for Prompt Shield leakage detection

Section 5's Prompt Shield Filter could be read as another LLM call reviewing the Teacher Engine's output. For the solution-leakage half specifically (the Teacher revealing more than the learner's current hint level permits), we use deterministic checks instead: substring/near-match comparison of Teacher output against the Pre-Flight-verified reference solution, gated by the learner's current hint level. This is ground truth we already have from Pre-Flight validation, so it doesn't need another model call, is cheaper, and is not itself vulnerable to the same injection classes an LLM-based checker would be. The prompt-injection half of the guardrail (as opposed to leakage) is left open — a deterministic check may not be sufficient there, and an LLM-based check remains an option if needed.
